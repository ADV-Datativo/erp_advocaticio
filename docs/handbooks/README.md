# Handbooks — ADV Easy / Datativo Labs

Documentação oficial da plataforma. Crescimento incremental — só os 5
documentos de uso imediato foram criados agora (Sprint 11); os demais
(UI, Theme, Development, Security, API, Supabase, Testing, Release)
nascem quando houver conteúdo real de cada sprint futura pra documentar.

1. [Architecture Handbook](architecture-handbook.md) — visão consolidada da arquitetura
2. [Component Handbook](component-handbook.md) — os 8 componentes da Datativo UI

4. [ADR](adr/) — Architecture Decision Records (6 decisões registradas)
5. [Changelog](../../CHANGELOG.md) — histórico cronológico (na raiz do repositório)

## Por que estes 5 primeiro
Mesmo raciocínio já usado quando adiamos o "Manual Oficial de 80-120
páginas" no início da migração: documentação madura demais, escrita
antes da prática validar a teoria, tende a precisar reescrita completa
depois. Estes 5 têm uso imediato — orientam qualquer pessoa (ou
instância futura do Claude) que abrir uma sessão nova neste projeto.
